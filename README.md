# 旅图 · LvTu

为航旅纵横添加航线离线地图的 LSPosed 模块，支持普通二维地图和卫星地图

当前仅在 **航旅纵横 8.6.8（700）** 上测试过，点开行程，进入地图，在右边添加了一个下载按钮

最近不做飞机，所以后续也没有数据测试，出现 Bug 暂时无法修复，短期内也不会更新…

- 沿航线按自定义距离和最大 Zoom 下载，默认每侧 2 km，支持输入及滑块调整
- 可单独下载出发机场、到达机场或两端机场半径 N km 的圆形区域，支持虚线范围预览，机场坐标读取自已有行程缓存
- 二维与卫星缓存分开保存，卫星支持离线地名标注，断网可缩放并使用低级瓦片放大回退
- 4 路协程并发下载，失败自动退避重试，启动续传，手动暂停后保持暂停
- 显示下载进度与通知，支持暂停、继续及删除任务
- 按样式和 Zoom 统计、叠加标记及删除缓存，可按所选航线清理范围外的缓存
- 仅充电时执行低优先级缓存核验，同轮支持断点继续，新轮至少间隔 24 小时

需要 LSPosed，作用域选择航旅纵横，当前仅提供 ARM64 构建，其他架构未适配

默认隐藏桌面图标，可从 LSPosed 的模块设置入口初始化通知权限

新包名为 `com.ohyooo.lvtu`，从旧模块迁移时先停用旧模块，已有缓存和参数会自动迁移

应用层使用 Kotlin，构建使用本地 JDK 25，JVM target 为 25

```shell
./gradlew :app:assembleDebug -x test -x lint
```
